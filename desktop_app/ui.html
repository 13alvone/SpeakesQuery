    Create Ingestion Script

    Unique name. Letters, digits, spaces, hyphens, underscores.

    Sandbox: pandas, requests, json, datetime, time, re, math, hashlib, base64, collections, io, bs4, lxml. Must call GENERATE_RESULTS(df). Access stored API keys via CREDENTIALS['key_name']. Press Ctrl+Space for autocomplete. Ctrl+/ to toggle comments.

    5-field cron: minute hour day month weekday

    Output path under indexes/. Supports nesting with '/' (e.g. github/issues). Defaults to title if blank.

    Append creates a new file each run; compaction merges small files automatically.

    Reference URL for documentation purposes.

    Library scripts suffixed _pro require Unrestricted. The Script Library's Deploy button sets this automatically; leave as Sandboxed unless you know you need scipy / sklearn / rapidfuzz / tuple-unpacking.

    Per-task wall-clock cap. Leave blank to inherit the global default_script_timeout_seconds setting. Deploying from the library auto-fills this from the script's suggested_timeout_seconds hint (e.g. options_unusual_activity_pro requests 300s). Range: 10–3600.

    API Credentials

    Credentials saved here will be attached to this script when saved.

    Script Guide

    import pandas as pd
import requests

resp = requests.get(
  "https://api.example.com/items",
  headers={
    "Authorization":
      f"Bearer {CREDENTIALS['api_key']}"
  }
)
data = resp.json()

df = pd.DataFrame(data["items"])

# Must call this with your DataFrame:
GENERATE_RESULTS(df)

# DataFrame must contain either:
# - _epoch column, OR
# - TIMESTAMP / DATE / CREATED_AT
#   (auto-converted to _epoch)
